# S5 手动验证方法(真题模考与成绩报告)

> 接口:GET /api/exam/list、GET /api/exam/{id}、POST /api/exam/{id}/submit、GET /api/exam/submission/{submissionId}/report、GET|PUT /api/exam/{id}/progress(扩展 E2)
> 数据库脚本:V05(模考三表)、S03(exam-2026 试卷,答案按答题卡全局编号 1-45)
> 批改状态机:AI → 交卷即出客观分(partially_graded)→ 异步 AI 作文评分 → graded;人工 → pending → 约 1 分钟后客观部分流转 partially_graded(作文待批)

## 2. 接口验证(Swagger UI;先登录并 Authorize)

### 2.1 列表与整卷

| # | 操作 | 预期 |
|---|---|---|
| 1 | GET /api/exam/list | PageResult;含 exam-2026;首次无 lastScore/lastSubmittedAt(无提交时) |
| 2 | GET /api/exam/list?year=2026 | 同 1;year=2025 → 空列表 |
| 3 | GET /api/exam/exam-2026 | sections 5 段;part1 阅读 content 为 3 篇数组;无 answer/explanation 字段 |
| 4 | GET /api/exam/xxx(不存在) | code=404「试卷不存在」 |

### 2.2 交卷(AI 模式,默认)

| # | 操作 | 预期 |
|---|---|---|
| 5 | POST /api/exam/exam-2026/submit,objective 填 45 个全局编号(如全对:参照 answer_key,可用下方 SQL 导出答案),writing 传 `{"content":"Dear ..."}`,duration=4200 | status=partially_graded;objectiveGraded=true;writingGraded=false;score=客观分;correctCount/totalCount(45) |
| 6 | 立即 GET /api/exam/submission/{submissionId}/report | sections 5 段(作文 score=0);objectiveGraded=true;writingGraded=false;score=客观分;weakPoints 按 <60% 生成 |
| 7 | 配置有效 AI key 后重复 5,等待异步作文评分完成(数秒~1 分钟) | 再次查询 report:writingGraded=true;writingScore 有值;score=客观+写作;status 变 graded |
| 8 | 无效 key 时执行 5:异步评分失败 | 保持 partially_graded;report 查询会兜底重试(日志有「模考作文 AI 评分失败…」) |

快速构造"全对"答案(可选,便于核对满分链路):

```sql
SELECT part, JSON_EXTRACT(section_json,'$.type') AS type, items_json FROM (
  SELECT JSON_EXTRACT(answer_key,'$.sections[0]') AS section_json,
         JSON_EXTRACT(answer_key,'$.sections[0].items') AS items_json, 1 AS part FROM exam_paper
) t;
-- 或在 Swagger 中按 1~15/16~20/21~35/36~45 逐段取 items[].id 与 answer 组装 objective
```

### 2.3 交卷(人工模式,延迟流转)

| # | 操作 | 预期 |
|---|---|---|
| 9 | 设置 gradingMethod=manual(或提交时传)后交卷 | status=pending;estimatedTime=「预计 24 小时内出结果」;无分数 |
| 10 | 等待约 1 分钟后再查 report | 客观部分已出分:objectiveGraded=true;status 数据层为 partially_graded;作文仍 writingGraded=false |

### 2.4 作答进度(扩展 E2)

| # | 操作 | 预期 |
|---|---|---|
| 11 | PUT /api/exam/exam-2026/progress `{"objective":{"1":"B","16":"A"},"writing":{"content":"..."},"duration":600}` | code=0 |
| 12 | GET 同路径 | data 与保存一致 |
| 13 | 交卷成功后 GET | data=null(进度已清除) |

## 4. 前端验证(关 MSW)

1. `/exam` 列表:显示 exam-2026 套卷;交卷出分后卡片出现「上次得分」。
2. `/exam/exam-2026` 完整答题(五部分 Tab + 底部答题卡 1-45)→ 交卷:

3. 报告页:总分/各题型得分/薄弱项/历年对比与后端数据一致。
