# S3 手动验证方法(题库与刷题主链路)

> 接口范围:GET /api/practice/list、GET /api/practice/detail/{type}/{id}、POST /api/practice/detail/{type}/{id}/submit、GET|PUT /api/practice/detail/{type}/{id}/progress(扩展 E1 断点续答)
> 数据库脚本:V03(题库与刷题四表)、S02(题库种子 10 题)
> 批改口径:AI 模式且有答案 → 提交即比对出分;人工模式 → 先 pending,约 1 分钟后自动出分;写作/无答案 → 转人工 pending

## 2. 接口验证(Swagger UI;先登录并把 token 填入 Authorize)

### 2.1 列表与详情

| # | 操作 | 预期 |
|---|---|---|
| 1 | GET /api/practice/list?type=reading&source=real&page=1&size=10 | PageResult;1 条(2023年真题阅读);submitted=false(未做过时) |
| 2 | source=ai(非法) | code=1005「source 仅接受 real 或 teacher」 |
| 3 | type=xxx(非法) | code=1004「题型参数缺失或不合法」 |
| 4 | GET /api/practice/detail/reading/reading-real-2023-1 | content 的 questions 仅含 id/stem/options,**无 answer/explanation**(答案不下发) |
| 5 | detail 不存在 id | code=404「题目不存在」 |

### 2.2 提交(AI 模式,默认)

| # | 操作 | 预期 |
|---|---|---|
| 6 | POST .../reading-real-2023-1/submit,body `{"answers":{"1":"B","2":"C","3":"B","4":"B","5":"B"},"duration":300}` | status=graded;gradingMethod=ai;score=10.0;correctCount=5;details 5 条全 true(含 correctAnswer/explanation) |
| 7 | 故意错两空(如 1:A、4:D) | score=6.0;details 中对应两条 isCorrect=false |
| 8 | 语法填空:POST .../grammar-real-2023-1/submit 按 answer_key 作答 | 判分含去空格与替代答案逻辑;大小写敏感度由设置页开关控制 |

### 2.3 提交(人工模式,先 pending 后自动出分)

| # | 操作 | 预期 |
|---|---|---|
| 9 | 先 PUT /api/user/settings `{"gradingMethod":"manual"}`,再提交任意客观题 | status=pending;gradingMethod=auto;estimatedTime=「预计 24 小时内出结果」;无 score/details |
| 10 | 等待约 1 分钟(阈值 60 秒 + 扫描间隔 30 秒) | 定时任务自动完成比对,提交变为 graded(见 SQL 抽查);错题本同步收录 |
| 11 | 提交后把设置改回 `{"gradingMethod":"ai"}` | 后续提交恢复即时出分 |

### 2.4 写作与无答案题目(当前统一转人工)

| # | 操作 | 预期 |
|---|---|---|
| 12 | POST .../writing-real-2023-1/submit,body `{"answers":{"content":"Dear Peter, ..."},"duration":900}` | status=pending;gradingMethod=manual;estimatedTime 非空(S4 接入 Spring AI 后 AI 模式将改为自动评分) |

### 2.5 作答进度(扩展 E1,断点续答)

| # | 操作 | 预期 |
|---|---|---|
| 13 | PUT .../reading-real-2023-1/progress,body `{"answers":{"1":"B","2":"C"},"duration":120}` | code=0 |
| 14 | GET 同路径 | data 与保存内容一致 |
| 15 | 对该题 POST submit 成功后再 GET | data=null(提交后进度自动清除) |

## 3. SQL 抽查

```sql
-- 提交与批改状态(pending 等待约 1 分钟后应变为 graded,estimated_time 清空)
SELECT id, question_id, status, grading_method, score, correct_count, total_count, estimated_time, graded_at
FROM practice_submission ORDER BY id DESC LIMIT 5;

-- 错题自动收录(批改完成后,答错的题逐条入库)
SELECT id, question_id, type, stem, user_answer, correct_answer FROM mistake ORDER BY id DESC LIMIT 5;

-- 作答进度:保存后存在、提交成功后删除
SELECT * FROM practice_progress;
```

## 4. 前端验证(关 MSW)

1. `.env.development.local`(VITE_USE_MOCK=false)+ `npm run dev`。
2. 登录后进入任一题型页(如 /practice/reading):来源切换「真题/模拟题」列表来自后端(S02 种子)。
3. 完成一套阅读(5 题)提交:AI 模式下即时进入批改态(绿色正确/红色错误 + 展开解析)。
4. 把设置页批改方式切为「人工批改」后再做一套:pending 占位页出现;约 1 分钟后刷新可出结果(S7 提供"我的提交"入口,当前可通过 SQL 或重复提交观察)。
5. 错题本等到 S7 页面接口上线后可查看;此前可用 SQL 抽查收录结果。
