## 1. 前端断点续答对接(扩展契约 E1/E2,已完成)

| 文件 | 变更 |
|---|---|
| `frontend/src/api/practice.ts` | 新增 `getPracticeProgress` / `savePracticeProgress`(E1) |
| `frontend/src/api/exam.ts` | 新增 `getExamProgress` / `saveExamProgress`(E2) |

自检:`npm run type-check` 通过(退出码 0)。

行为口径:进入同一题(同设备或换设备登录)未提交作答自动恢复;提交/交卷成功后进度清除(再次进入为空白)。

## 2. 联调启动步骤

1. 启动 MySQL(服务 `MySQL`;管理员 `net start MySQL`)。
2. 首次从零初始化:按 `backend/src/main/resources/db/README.md` 顺序执行全部 V/S 脚本(V01→V07,S01→S06)。
3. 启动后端:`cd backend` → `.\mvnw.cmd spring-boot:run`;确认 `/actuator/health` UP、`/swagger-ui.html` 可开。
4. 前端:`frontend/.env.development.local` 写 `VITE_USE_MOCK=false` → `npm run dev`。
5. 断点续答走查:任一题型进入答题→答 2 题→刷新页面重进同题→作答保留;提交后重进为空白;模考同理。

## 3. 数据库全量序列复核(从零可复现)

空库复现检查单:依次执行 V01→V02→S01→V03→S02→V05→S03→V06→S04→S05→V07→S06,每条退出码为 0;随后抽查:

```sql
SELECT (SELECT COUNT(*) FROM user) AS users, (SELECT COUNT(*) FROM question) AS questions,
       (SELECT COUNT(*) FROM exam_paper) AS papers, (SELECT COUNT(*) FROM vocab_word) AS words,
       (SELECT COUNT(*) FROM grammar_section) AS sections, (SELECT COUNT(*) FROM favorite) AS favorites;
-- 期望:users≥1 / questions=10 / papers=1 / words=20 / sections=12 / favorites=2
```
