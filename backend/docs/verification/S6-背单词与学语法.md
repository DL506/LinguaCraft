## 2. 接口验证(Swagger UI;先登录并 Authorize)

### 2.1 背单词

| # | 操作 | 预期 |
|---|---|---|
| 1 | GET /api/vocab/books | 3 本词书;learned 随进度变化(新用户为 0) |
| 2 | GET /api/vocab/book/book-syllabus/words?page=1&size=20 | 20 词(全部);分页字段齐全 |
| 3 | GET /api/vocab/book/book-high/words | 仅 high 层 8 词;book-core → core 层 6 词 |
| 4 | GET /api/vocab/book/xxx/words | code=404「词书不存在」 |
| 5 | POST /api/vocab/review `{"wordId":"w-001","rating":"known"}` | code=0;再次执行 task/today 的 doneCount +1;book-syllabus 的 learned +1 |
| 6 | POST /api/vocab/review `{"wordId":"w-001","rating":"bad"}` | code=400「记忆自评仅接受 unknown/fuzzy/known」 |
| 7 | GET /api/vocab/task/today | newCount(今日首学)/reviewCount(待复习)/doneCount(今日复习数)/target(设置页目标,默认 50) |
| 8 | GET /api/vocab/task/due | 刚复习过的词不在列(尚未到期);SQL 改 next_review_at 为过去时间后可验证到期出现 |

```sql
-- 到期验证辅助:把某词下次复习时间改为过去,再调 task/due 应能查到
UPDATE user_word_progress SET next_review_at = NOW() - INTERVAL 1 DAY WHERE user_id = 1 LIMIT 1;
```
