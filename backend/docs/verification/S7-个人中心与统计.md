## 2. 接口验证(Swagger UI;先登录 demo 并 Authorize)

### 2.1 我的提交

| # | 操作 | 预期 |
|---|---|---|
| 1 | GET /api/user/submissions | 3 条演示提交(新→旧);含 source/status/score/estimatedTime |
| 2 | GET /api/user/submissions?status=pending | 仅待批改(pending manual 写作;pending auto 阅读在流转前后可见/消失) |
| 3 | GET /api/user/submissions?status=graded | 已批改记录(含阅读 6.0) |
| 4 | GET /api/user/submissions/{id:id=1} | 完整 SubmitResult:details 5 条(3 对 2 错,含解析);score=6.0 |
| 5 | 查 pending 写作详情(id=2) | 无 details、无 score;estimatedTime=「预计 24 小时内出结果」 |
| 6 | 不存在/他人 id | code=404「提交记录不存在」 |
| 7 | status=bad | code=400「status 仅接受 all/graded/partially_graded/pending」 |

### 2.2 错题本

| # | 操作 | 预期 |
|---|---|---|
| 8 | GET /api/user/mistakes | 2 条(阅读细节题 + 完形填空) |
| 9 | GET /api/user/mistakes?source=teacher | 仅 teacher 来源 1 条 |
| 10 | GET /api/user/mistakes?type=cloze | 仅完形 1 条 |
| 11 | DELETE /api/user/mistakes/{id=2} 再查 | 删除成功;列表剩 1 条;重跑 S06 可恢复演示数据 |
| 12 | DELETE 不存在 id | code=404「错题不存在」 |

### 2.3 收藏

| # | 操作 | 预期 |
|---|---|---|
| 13 | GET /api/user/favorites | 2 条(abandon 单词 + 句子) |

| 15 | POST type=bad 或 content 空 | code=400 对应文案 |
| 16 | DELETE /api/user/favorites/{新 id} | 删除成功,列表恢复 2 条 |

| # | 操作 | 预期 |

## 3. SQL 抽查

```sql
SELECT id, title, status, score FROM practice_submission WHERE user_id = 1 ORDER BY id DESC;
SELECT id, question_id, type FROM mistake WHERE user_id = 1;
SELECT id, type, content FROM favorite WHERE user_id = 1;
SELECT r.id, r.status, r.grading_method, r.graded_at FROM practice_submission r WHERE r.id = 3; -- 流转后 graded
```

## 4. 前端验证(关 MSW)

1. 个人中心「学习统计」:4 统计卡与双图有数据;「待批改」数与首页提示一致。
2. 「我的提交」:四态筛选与详情抽屉(表格/卡片)与后端一致;pending 显示预计时间;graded 展示逐题明细与错题解析。
3. 「错题本」:来源/题型筛选、删除、重做跳转 `/practice/{type}?id={questionId}&from=mistakes`。
4. 「收藏」:分组列表;单词页/阅读选中句子可新增;删除生效。
5. 「我的词书」:learned 与背单词进度联动;首页「你有 N 份提交待批改」→「查看」跳 `/user/submissions?status=pending`(验收 31/33)。
